How User Roles Work

When someone posts a message in Microsoft Teams, the automation checks their role. Clients have their bug reports automatically drafted as Jira issues. Project Managers (PMs) receive triage cards to approve or reject issues. Developers are automatically routed and suggested based on their designated specialty.

Jira Cloud Connection

Approved bug tickets are automatically created inside your Jira Cloud workspace. Use your Atlassian service account email and an API token generated from your Atlassian Security profile.

Multi-Key Failover Pool & Model Selection

To prevent rate limits during heavy client bug reporting, the system supports a pool of Gemini API keys. If Key 1 is throttled (HTTP 429), Key 2 automatically takes over without failing user requests.
